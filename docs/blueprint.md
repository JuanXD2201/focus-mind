# **App Name**: Serene Productivity

## Core Features:

- User Authentication: User authentication using Firebase Authentication (email/password).
- Personal Calendar: Personal calendar display with event management (stored in Firestore).
- Surveys: Display simple survey questions; record user responses.
- Role-Based Dashboard: User role-based dashboard (user/admin).
- Admin Dashboard: Display user statistics on admin dashboard (active users, completed surveys).
- Landing Page: Display of welcome message and navigation options on home page.

## Style Guidelines:

- Primary color: Soft violet (#A089CE) for promoting calmness and focus.
- Background color: Light purple (#F1E6FF), very desaturated to create a restful atmosphere.
- Accent color: Muted blue (#7B9ACC) to complement the violet.
- Body and headline font: 'Inter' (sans-serif) for a modern, clean aesthetic.
- Minimalist layout with clear content sections.
- Subtle animations on button hover effects and page transitions.
